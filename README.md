
# Gestion des tâches Python

## Description
Application Python simple permettant de gérer les tâches quotidiennes à partir d'une interface console.

## Fonctionnalités
- Ajouter une tâche.
- Afficher toutes les tâches avec leur numéro.
- Rechercher une tâche par mot-clé.
- Refuser les titres vides.
- Quitter le programme.

## Étapes réalisées
- Création du fichier main.py.
- Développement du menu principal.
- Ajout de la fonctionnalité d'ajout des tâches.
- Ajout de l'affichage des tâches.
- Ajout de la recherche par mot-clé.
- Test du fonctionnement du programme.

## Exécution du programme
1. Ouvrir le projet dans Visual Studio Code.
2. Ouvrir le fichier main.py.
3. Cliquer sur le bouton **Run Python File**.
4. Utiliser le menu dans le terminal.
